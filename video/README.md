# Growing up, together. — Kahshe Lake family film

- `final.mp4` — the film (1920x1080, 30 fps, 59.7 s, with sound)
- `hf-project/` — the HyperFrames project. Render: `cd hf-project && npx hyperframes render -o final.mp4 --fps 30` (needs ffmpeg + ffprobe on PATH). Rebuild the sound: `python3 tools/make_audio.py` (numpy, scipy).
- `storyboard/` — key stills
- `BREAKDOWN.md`, `LOG.md`, `LESSONS.md`
